# Machine Learning & Data Mining Assignments

This repository contains a collection of assignments completed during a Master's-level course in Machine Learning and Data Mining at the **University of Neuchâtel**, as part of the [Swiss Joint Master in Computer Science](https://mcs.unibnf.ch/).

The work was carried out under the instruction of **Prof. Christos Dimitrakakis** and focuses on the practical implementation and analysis of core machine learning methods.

The official course repository is available here:  
[Machine Learning Course Repository](https://github.com/olethrosdc/machine-learning-neuch/tree/main/MSc)

---

## Overview

This repository showcases hands-on experience with fundamental machine learning concepts, combining theoretical understanding with practical implementation and experimentation.

Covered topics include:

- Instance-based learning (K-Nearest Neighbors)
- Model generalization and hyperparameter tuning
- Linear models (Perceptron, Logistic Regression)
- Neural networks
- Bayesian inference and probabilistic modeling

All assignments are implemented in Python using Jupyter notebooks, with a focus on clarity, reproducibility, and structured analysis.

---

## Assignments

The repository includes the following assignments:

1. **K-Nearest Neighbors (KNN)**  
2. **Generalization & Hyperparameter Tuning**

4. **Perceptron & Logistic Regression**
